# Denda-Online

Denda-Online es un plugin para Claude que ayuda a gestionar una tienda online: consultar productos, revisar pedidos y preparar descripciones de catálogo. Su objetivo es ahorrar tiempo en las tareas repetitivas del comercio electrónico.

## Uso

Instala el plugin desde Claude y pide, por ejemplo, "resume los pedidos de hoy" o "escribe una descripción para este producto".

## Configuración

No requiere configuración adicional. Si se conecta con una tienda externa, indica la URL y las credenciales cuando Claude las solicite.
